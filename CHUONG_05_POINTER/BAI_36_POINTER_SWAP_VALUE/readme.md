Bạn được cho hai số nguyên a và b. Hãy viết một hàm để hoán đổi giá trị của chúng bằng cách sử dụng con trỏ (pointers). Bạn phải truyền địa chỉ của cả hai biến này vào hàm. Sau khi hoán đổi, hãy in ra giá trị mới của chúng trong hàm `main()`.

**Ví dụ 1**

* **Đầu vào:** `a = 10, b = 20`
* **Đầu ra:** `a = 20, b = 10`

**Ví dụ 2**

* **Đầu vào:** `a = -5, b = 15`
* **Đầu ra:** `a = 15, b = -5`
