Bạn được cấp một thanh ghi 8-bit. Hãy đếm xem có bao nhiêu bit được đặt thành 1 (tức là mức cao) trong thanh ghi đó.

Ví dụ 1

Đầu vào: reg = 0b0000 1111

Đầu ra: 4

Ví dụ 2

Đầu vào: reg = 0b1111 0000

Đầu ra: 4

Ví dụ 3

Đầu vào: reg = 0b0000 0000

Đầu ra: 0

Ví dụ 4

Đầu vào: reg = 0b1111 1111

Đầu ra: 8
