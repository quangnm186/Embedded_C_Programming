Viết một chương trình C để kiểm tra xem bit thứ K (chỉ số tính từ 0) của số nguyên N đã được bật (là 1) hay chưa (là 0).

Định dạng đầu vào:

Hai số nguyên N và K.

Định dạng đầu ra:

In ra 1 nếu bit thứ K của số nguyên N được bật (1), ngược lại in ra 0.

Ví dụ:

Đầu vào: N = 8 & K = 3

Giá trị nhị phân của 8 là 00001000

Đầu ra: 1
