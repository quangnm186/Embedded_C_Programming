Bạn được cho một thanh ghi 16-bit (uint16_t).

Nhiệm vụ của bạn là:

Trả về một giá trị mà trong đó chỉ giữ lại bit được bật (bit 1) cao nhất (nằm ngoài cùng bên trái).

Tất cả các bit khác đều phải được xóa về 0.

Ví dụ 1

Đầu vào: 44 // Dạng nhị phân: 0000000000101100

Đầu ra: 32 // Dạng nhị phân: 0000000000100000

Ví dụ 2

Đầu vào: 512 // Dạng nhị phân: 0000001000000000

Đầu ra: 512 // Dạng nhị phân: 0000001000000000

Ví dụ 3

Đầu vào: 255 // Dạng nhị phân: 0000000011111111

Đầu ra: 128 // Dạng nhị phân: 0000000010000000
